# Code and story rights

The repository license governs software source and generated software
artifacts. It does not grant rights to *Path of Angels* episode video, Blender
files, scripts, characters, setting, logos, music, voice, or other story and
media assets owned by their respective creators.

Short setting phrases embedded in the terminal are present for private
collaboration on the game adaptation. Before public release, the maintainers
should record an explicit content/brand license and keep it distinct from the
AGPL software license.
